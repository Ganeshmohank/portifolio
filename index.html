Cybersecurity

Palo Alto Networks

Staff Software Engineer, Machine Identity Management. CyberArk R&D, Santa Clara. June 2026 to present.

I work on machine identity, end to end, from schema and backend APIs to the customer-facing UI.

  1. Signed by the root

    Machine identity is what I work on. Every service proves who it is with a certificate that chains back to a trusted root.

  2. Encrypted in transit

    With an identity it can prove, one service can talk to another over mutual TLS. Anyone watching the wire sees noise.

  3. Access groups

    I replaced all-or-nothing RBAC with granular access groups. Least privilege is now a shared layer that services enforce by default.

  4. Audit trail

    I moved the platform's audit trail onto Palo Alto's central logging after the acquisition, one environment at a time, behind feature flags.

ServiceNow

Software Engineer, internal AI platform. Santa Clara. May 2025 to May 2026.

I shipped a RAG support agent that resolves recurring tickets on its own, and the retrieval and tooling underneath it.

  1. Tickets in

    Repeating "how-to" tickets arrive, the ones that eat up a support team's week.

    2.6k tickets auto-handled

  2. Retrieval

    Knowledge-base retrieval and Now APIs fetch what an answer actually needs.

  3. Memory

    A context memory layer retains ticket history, so nobody has to explain twice.

    54% to 82% one-touch resolutions, handle time down 18%

  4. Routing

    Dynamic model routing sends low-risk asks to faster models.

    9.3s to 5.7s median latency, token spend down 22%

  5. Model

    The LLM drafts an answer from what was retrieved and remembered.

  6. Guards

    Validation checks every answer's structure and facts before anyone sees it.

    37% lower hallucination rate

  7. Deflected

    The sparks breaking away are the tickets that never needed a person, exactly 31% of them.

    31% deflection, an estimated 400 hours saved a quarter
